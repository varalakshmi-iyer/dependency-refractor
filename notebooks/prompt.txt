Create a complete Spring Boot 3.2 Java 17 Gradle project called "DepAssist" 
for Citi's internal dependency intelligence platform. The tool helps 
engineering teams identify duplicate, unused, and conflicting dependencies 
across their Spring Boot microservices, reducing CVE exposure by eliminating 
redundant libraries.

════════════════════════════════════════════════════════
PLAYBOOKSERVICE.JAVA
════════════════════════════════════════════════════════

@Service, reads playbook.yaml using SnakeYAML.

@Value("${deptool.playbook-path}") private String playbookPath;

Two public methods:

1. Map<String, Object> readRaw() throws IOException
   - Reads the yaml file as a nested Map
   - Returns empty LinkedHashMap if file is empty

2. PlaybookSummary getSummary() throws IOException
   - Calls readRaw() internally
   - Extracts library_categories, categories, meta from the map
   - Builds categoryCounts: Map<String, Integer> counting artifacts per category
   - Builds List<DuplicateCluster> from the categories section
   - Builds uncategorized list: artifacts in library_categories but NOT in any
     cluster's artifact list
   - Returns fully populated PlaybookSummary

All map casts use @SuppressWarnings("unchecked").

════════════════════════════════════════════════════════
AUDITSERVICE.JAVA
════════════════════════════════════════════════════════

@Service, reads/writes audit.json using Jackson ObjectMapper.

Constructor registers JavaTimeModule on the ObjectMapper.

@Value("${deptool.audit-path}") private String auditPath;

Three public methods:

1. List<AuditRecord> readAll() throws IOException
   - Creates the file with content "[]" if it does not exist
   - Deserializes using TypeReference<List<AuditRecord>>

2. synchronized AuditRecord append(AuditRecord record) throws IOException
   - Reads current list, adds record, writes back with pretty printer
   - Returns the appended record

3. Map<String, Object> getAuditResponse(int limit, String serviceNameFilter)
     throws IOException
   - Reads all records
   - Filters by serviceNameFilter if not null/blank (case-insensitive contains)
   - Sorts newest-first by timestamp
   - Returns LinkedHashMap with keys "total" (int) and "records" (List, paged)

4. Map<String, Object> getAuditStats() throws IOException
   - Returns LinkedHashMap with:
     "total": records.size()
     "uniqueServices": distinct service names count
     "totalDependenciesValidated": sum of all dependenciesValidated
     "totalClustersFound": sum of all duplicateClustersFound

APICONTROLLER.JAVA
════════════════════════════════════════════════════════

@RestController @RequestMapping("/api")
Constructor-injected PlaybookService and AuditService.

Endpoints -- all return ResponseEntity, catch Exception and return 500:

GET /api/health
  Returns: status, playbookArtifacts, playbookClusters, lastUpdated, totalAudits

GET /api/playbook
  Returns: full playbook as Map<String, Object> (for offline clients and Devin)

GET /api/playbook/summary
  Returns: PlaybookSummary object

GET /api/audit
  @RequestParam(defaultValue="50") int limit
  @RequestParam(required=false) String serviceName
  Returns: Map with "total" and "records"

GET /api/audit/stats
  Returns: Map with total, uniqueServices, totalDependenciesValidated,
           totalClustersFound

POST /api/audit/record
  All @RequestParam:
    String serviceName
    String validationMode
    int dependenciesValidated
    int duplicateClustersFound
    int uncategorizedCount
    @RequestParam(defaultValue="api") String triggeredBy
  Creates AuditRecord via AuditRecord.create(), calls auditService.append()
  Returns: Map with "status":"recorded" and "id": record.getId()

QUALITY REQUIREMENTS
════════════════════════════════════════════════════════

1. Every Java file must compile cleanly with no missing imports.
   Include all import statements at the top of each file.

2. Every Thymeleaf expression must be valid:
   - Use th:if, th:each, th:text, th:classappend, th:href correctly
   - Date formatting: #temporals.format(record.timestamp, 'dd MMM yyyy')
   - List check: #lists.isEmpty(list), #lists.size(list)
   - Map access: map['key'] or map.key
   - String operations: str.replace('_',' ')

3. The application must start with:
   ./gradlew bootRun
   and serve the UI at http://localhost:8080

4. The two data files (playbook.yaml, audit.json) must be read on every
   request -- NOT cached at startup -- so Devin commits are reflected
   immediately without a server restart.

5. All map casts from SnakeYAML output use @SuppressWarnings("unchecked").

6. AuditService.append() must be synchronized for thread safety.

7. PlaybookSummary.getUncategorized() must return artifacts that appear in
   library_categories but do NOT appear in any category's artifact list.
