Phase 1 — Playbook foundation Devin + UI, no team input needed
Devin playbook generation
Clones repos, scans jars, calls LLM in batches of 25 to categorize artifacts
playbook.yaml in git
Every Devin run commits a readable diff to Bitbucket — fully auditable, reversible
Playbook viewer tab
Thymeleaf UI shows clusters, recommendations, reasons, uncategorized list, raw yaml
Audit trail tab
Service name, date, deps validated, clusters found, triggered by — filterable table
Spring Boot REST API
GET /playbook, GET /audit, POST /audit/record — offline clients cache the playbook response
Brainstorm playbook (separate)
Second LLM call covers common Java ecosystem patterns beyond your own repos
Phase 2 — Offline validation for all teams No Devin, no LLM needed at runtime
/analyze/text
Paste group:artifact:version list — supports all coordinate formats, one per line
/analyze/repo
GitHub / Bitbucket URL — clones, parses all build.gradle, multi-module aware
/analyze/jar (Artifactory)
JFrog Artifactory URL — downloads jar, reads BOOT-INF/lib, exact class-level detection
Consistent response shape
All three modes return: clusters, recommended, reason, uncategorized — same JSON every time
Validation UI tab
Service teams submit via form — sees results instantly without API knowledge
Audit trail extended
Adds input mode column (text / repo / jar) — distinguishes Devin vs team validations
Phase 3 — Snyk + CVE intelligence Security posture metric, not just hygiene
Snyk CVE enrichment
Per artifact: CVE count, severity breakdown (critical/high/medium) via Snyk API
CVE reduction tracking
Before/after CVE snapshot per run — total CVEs reduced tracked in audit.json
Priority score per cluster
CVE severity × services affected × safe replacement exists = remove this first
Fleet CVE dashboard
Total CVEs removed all time, critical removed, most impactful artifact removal
PR gate integration
CI step fails build if new dep duplicates playbook or introduces HIGH/CRITICAL CVE
Dependency trend tracking
Per-service dep count over time — surfaces teams adding 5+ deps per sprint early
Blast radius calculator
How many services affected if X is removed from the approved list — prioritizes migration
Fleet standardization scorecard
% deps in approved playbook, CVEs outstanding — reportable to SVP/CISO level
